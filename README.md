# GTA-MTP

We're developing our own GTA-inspired game engine called Multi Theft Philippine (MTP), inspired by the concept and functionality of Multi Theft Auto (MTA).

Our goal is to create a multiplayer platform similar to MTA, powered by Unity, with support for streaming assets directly from an existing Grand Theft Auto: San Andreas installation.

This is not intended to be a complete reimplementation of GTA: San Andreas. Instead, we're building our own game engine and multiplayer framework, taking inspiration from MTA while developing unique systems, features, and gameplay experiences tailored for the Philippine gaming community.
